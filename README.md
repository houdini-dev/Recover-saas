# Recover

**Recover** is a customer recovery and follow-up SaaS for small businesses.

> Recover leads, reservations and repeat customers before they disappear.

## MVP

- Customer pipeline
- Follow-up queue
- Revenue-at-risk dashboard
- AI-assisted follow-up messages
- WhatsApp handoff without requiring the WhatsApp API
- Responsive dashboard
- Multi-business model (restaurants, services, beauty and more)

## Product direction

Recover is built around a simple problem: small businesses often lose revenue because leads, quotes, reservations and repeat customers are forgotten. The product turns those situations into visible follow-up actions.

The first version intentionally avoids paid infrastructure and official WhatsApp API dependencies so the product can be validated at near-zero cost.

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
